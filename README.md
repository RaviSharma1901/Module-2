# Module-2 Repository Overview

1. __Summative Assignment - Web Scraping__

2. __Exploratory Data Analysis (EDA) Project__  
* Examines **hotel booking patterns, cancellations, pricing impact, and guest behavior** using EDA techniques.  
* Key insights include **seasonal trends, retention rates, and booking stability**, visualized through **heatmaps & pairplots**.
